## @soroush.tech/styled-system@6.0.3

The check for a valid attribute accepts every UmberStyle release from 0.7 up to the next major
after 1, so an app on a newer UmberStyle installs one copy of it. No public API changes.

### Packaging

- `@umber-style/is-prop-valid` is accepted from `0.7.0` up to, not including, `2.0.0`
  (`>=0.7.0 <2.0.0`); it was `^0.7.0`, which takes only 0.7.x. An app whose UmberStyle is 0.8 or
  later had a second copy of it, kept at 0.7 for this package alone.
